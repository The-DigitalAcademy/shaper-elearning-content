    <h3 style="color: #111;">Scripting &amp; Compiling Languages</h3>
    <p>Not all programming languages are the same—each is designed with specific
      strengths and use cases in mind. As a developer, choosing the right language
      depends on what you want to build, whether it’s a web app, game, mobile
      application, or data system. Understanding how different languages work will
      help you make better technical decisions.</p>
    <div style="border-top: 1px solid #e5e7eb; margin: 16px 0;"> </div>
    <h5
      style="text-transform: uppercase; font-size: 0.8rem; letter-spacing: 0.05em; color: #6b7280; margin-bottom: 8px;">
      SCRIPTING LANGUAGES</h5>
    <p>Scripting languages are interpreted at runtime. When a computer language is
      interpreted at runtime, it means that the source code is not compiled into
      machine code before execution. Instead, an interpreter reads and executes the
      source code line by line or statement by statement as the program runs.</p>
    <p>They are often used for tasks that involve automation, rapid prototyping, and
      web development.</p>
    <p>Scripting languages are usually easier to learn and use, as they often have
      simpler syntax and dynamic typing. Dynamic typing in programming means that a
      language figures out the type of a variable while the program is running.</p>
    <p>Examples of scripting languages include <strong>JavaScript</strong>,
      <strong>Python</strong>, <strong>Ruby</strong>, and <strong>PHP</strong>.</p>
    <div style="border-top: 1px solid #e5e7eb; margin: 16px 0;"> </div>
    <h5
      style="text-transform: uppercase; font-size: 0.8rem; letter-spacing: 0.05em; color: #6b7280; margin-bottom: 8px;">
      Compiling LANGUAGES</h5>
    <p>Compiled languages are turned into machine code before they run. Compiling
      involves translating the source code into machine code that the computer can
      execute.</p>
    <p>They're commonly used for making powerful programs like system software and
      games.</p>
    <p>Examples of compiled languages are <strong>C</strong>, <strong>C++</strong>,
      <strong>Java</strong> (which is compiled to bytecode and then run by the Java
      Virtual Machine), and <strong>C#</strong> (which is compiled to Common
      Intermediate Language code for running on the .NET framework).</p>
    <blockquote><em>The way a language is executed affects performance, speed, and
        development flexibility.</em></blockquote>
