      thinking logically, solving problems, and building solutions that improve how

      PROGRAMMING CONCEPTS OVERVIEW</h5>
    <p>To begin learning programming, it is important to understand the core
      concepts that form the building blocks of all software. These concepts help
      you structure logic and control how a program behaves.</p>
    <div style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">
      <strong>Variables</strong>
      <p style="margin: 6px 0 0;">Variables store data that can be used and updated
        within a program, such as numbers, text, or user input.</p>
    </div>
    <div style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">
      <strong>Data Types</strong>
      <p style="margin: 6px 0 0;">Data types define the kind of data a variable can
        hold, such as integers, strings, or Boolean values.</p>
    </div>
    <div style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">
      <strong>Control Structures</strong>
      <p style="margin: 6px 0 0;">Control structures, such as loops and conditional
        statements, determine the flow of a program and allow decisions to be made.
      </p>
    </div>
    <div style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">
      <strong>Functions</strong>
      <p style="margin: 6px 0 0;">Functions are reusable blocks of code that perform
        specific tasks, helping to organise and simplify programs.</p>
    </div>
    <div style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">
      <strong>Algorithms</strong>
      <p style="margin: 6px 0 0;">Algorithms are step-by-step procedures used to
        solve problems or perform tasks within a program.</p>
    </div>
    <div style="border-top: 1px solid #e5e7eb; margin: 16px 0;">&nbsp;</div>
    <h5 style="text-transform: uppercase; font-size: 0.8rem; letter-spacing: 0.05em; color: #6b7280; margin-bottom: 8px;">
      PROGRAMMING PRINCIPLES OVERVIEW</h5>
    <p>Programming principles guide how code should be written to ensure it is
      efficient, maintainable, and easy to understand. These principles are
      essential for working in professional development environments.</p>
    <div style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">
      <strong>Readability</strong>
      <p style="margin: 6px 0 0;">Code should be clear and easy to understand so
        that others (and your future self) can work with it effectively.</p>
    </div>
    <div style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">
      <strong>Modularity</strong>
      <p style="margin: 6px 0 0;">Programs should be divided into smaller, reusable
        components or modules to improve organisation and scalability.</p>
    </div>
    <div style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">
      <strong>Efficiency</strong>
      <p style="margin: 6px 0 0;">Efficient code uses resources such as time and
        memory effectively, ensuring optimal performance.</p>
    </div>
    <div style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">
      <strong>Maintainability</strong>
      <p style="margin: 6px 0 0;">Code should be easy to update, fix, and extend as
        requirements change over time.</p>
    </div>
    <div style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">
      <strong>Reusability</strong>
      <p style="margin: 6px 0 0;">Well-designed code can be reused across multiple
        projects, reducing duplication and saving development time.</p>
    </div>
    <div style="border-top: 1px solid #e5e7eb; margin: 16px 0;">&nbsp;</div>
    <h5 style="text-transform: uppercase; font-size: 0.8rem; letter-spacing: 0.05em; color: #6b7280; margin-bottom: 8px;">
      PROGRAMMING TERMINOLOGY OVERVIEW</h5>
    <p>Programming terminology refers to the language used by developers to describe
      code, processes, and systems. Understanding these terms is essential for
      communication and collaboration in technical environments.</p>
    <div style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">
      <strong>Syntax</strong>
      <p style="margin: 6px 0 0;">The set of rules that defines how code must be
        written in a programming language.</p>
    </div>
    <div style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">
      <strong>Compiler / Interpreter</strong>
      <p style="margin: 6px 0 0;">Tools that translate written code into
        instructions that a computer can execute.</p>
    </div>
    <div style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">
      <strong>Debugging</strong>
      <p style="margin: 6px 0 0;">The process of identifying and fixing errors or
        bugs in a program.</p>
    </div>
    <div style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">
      <strong>Library / Framework</strong>
      <p style="margin: 6px 0 0;">Pre-written code that developers can use to
        perform common tasks more efficiently.</p>
    </div>
    <div style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">
      <strong>Runtime</strong>
      <p style="margin: 6px 0 0;">The period when a program is actively running and
        executing instructions.</p>
    </div>
