    <p>Before you can start coding, your computer needs to be properly prepared with
      the right tools and software. This process includes installing the necessary
      programs and configuring them so they work smoothly together.</p>
    <p>A well-configured development environment makes coding easier, improves
      productivity, and reduces technical issues as you learn and build projects.
    </p>

    <h5
      style="text-transform: uppercase; font-size: 0.8rem; letter-spacing: 0.05em; color: #6b7280; margin-bottom: 8px;">
      INSTALLATION</h5>
    <p>Installation is the process of adding the required software to your computer
      so that you can write and run code. This forms the foundation of your
      programming environment.</p>
    <div
      style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">
      <strong>Code Editor or IDE</strong>
      <p style="margin: 6px 0 0;">Install a tool where you can write and manage your
        code, such as a text editor or an Integrated Development Environment (IDE),
        which combines multiple development tools in one interface.</p>
    </div>
    <div
      style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">
      <strong>Compiler or Interpreter</strong>
      <p style="margin: 6px 0 0;">Install the tools that translate your code into
        instructions the computer can execute.</p>
    </div>
    <div
      style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">
      <strong>Libraries and Tools</strong>
      <p style="margin: 6px 0 0;">Add reusable code libraries and additional tools
        that help speed up development and add functionality to your projects.</p>
    </div>
    <div
      style="border-left: 4px solid #00C9B1; background: #f9fafb; padding: 12px 16px; margin: 16px 0;">
      <h5 style="margin-top: 0;">Key Insight</h5>
      <p style="margin-bottom: 0;">Installation ensures you have all the essential
        tools needed to begin coding and running programs successfully.</p>
    </div>
    <div style="border-top: 1px solid #e5e7eb; margin: 16px 0;"> </div>

      SET-UP</h5>
    <p>Once the necessary software is installed, setup ensures that everything is
      configured correctly for efficient and comfortable use.</p>
    <div
      style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">
      <strong>Adjust Settings</strong>
      <p style="margin: 6px 0 0;">Customise your editor or IDE settings, such as
        themes, formatting, and behaviour.</p>
    </div>
    <div
      style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">

      <p style="margin: 6px 0 0;">Structure your project folders and files for easy
        navigation and management.</p>

    <div
      style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">
      <strong>Add Extensions and Tools</strong>
      <p style="margin: 6px 0 0;">Install extensions or plugins that enhance your
        development experience.</p>
    </div>

      style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">

      <p style="margin: 6px 0 0;">Make sure all tools and software components work

    <p>The following example demonstrates how to install Python and set up a
      development environment using an IDE.</p>

      style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">
      <strong>1. Install Python</strong><br>
      <p>First, you need to install the Python computer language on your computer.
      </p>
      <p>You can download the Python installer from the official Python website:
        https://www.python.org/downloads/</p>
      <p><img class="img-fluid" role="presentation"

      <p>Find the downloaded and open the downloaded file.</p>
      <p><img class="img-fluid" role="presentation"

          alt="" width="2016" height="1564"></p>
      <p>Follow the installation instructions for your operating system.</p>
      <p><img class="img-fluid" role="presentation"
          src="https://raw.githubusercontent.com/The-DigitalAcademy/shaper-elearning-images/refs/heads/main/qcto-software-developer/install-python-3.png"

      <strong>2. Verify the Python Installation</strong><br>
      <p>Once Python is installed, you need to check if it's installed correctly by
        opening a command prompt (Windows) or terminal (macOS/Linux).</p>
      <p>On Mac, open <em>Apps</em> and search "Terminal".</p>
      <p><img class="img-fluid" role="presentation"
          src="https://raw.githubusercontent.com/The-DigitalAcademy/shaper-elearning-images/refs/heads/main/qcto-software-developer/verify-python-1.png"
          alt="" width="890" height="623"></p>
      <p>Type <code>python --version</code> in the terminal.</p>
      <p><img class="img-fluid" role="presentation"
          src="https://raw.githubusercontent.com/The-DigitalAcademy/shaper-elearning-images/refs/heads/main/qcto-software-developer/verify-python-2.png"
          alt="" width="709" height="497"></p>
      <p><em>Note that the terminal image shows an old version of Python, make sure
          to always use the newest stable version available.</em></p>

      <strong>3. Install an IDE</strong><br>
      <p>After installing Python, you may want to set up a development environment.

      <p>Download VSCode from the official website: https://code.visualstudio.com/
      </p>
      <p><img class="img-fluid" role="presentation"
          src="https://raw.githubusercontent.com/The-DigitalAcademy/shaper-elearning-images/refs/heads/main/qcto-software-developer/install-ide-1.png"

      <p>Follow the installation instructions for your operating system.</p>
      <p>Open Visual Studio Code and install the Python extension by clicking on the

        "Install".</p>

    </div>

      style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">
      <strong>4. Create Your First Python Programme</strong><br>
      <p>Create a new Python file by clicking on "File" &gt; "New File", and then
        saving the file with a .py extension, such as hello.py.</p>
      <p>You can also create a new file by clicking the <em>New File...</em> icon,
        entering the file name and extension, and pressing <em>Enter.</em></p>
      <p><img class="img-fluid" role="presentation"
          src="https://raw.githubusercontent.com/The-DigitalAcademy/shaper-elearning-images/refs/heads/main/qcto-software-developer/first-python-1.png"

      <p>Write some Python code in the editor:<br><code>print("Hello
          World!");</code></p>

        open the command palette, typing "Python: Run Python File in Terminal", and
        then pressing Enter.</p>
